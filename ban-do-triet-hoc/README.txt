BẢN ĐỒ TRIẾT HỌC - 20 CÂU TRẮC NGHIỆM

CẤU TRÚC
- index.html: toàn bộ website (HTML, CSS, JavaScript), có thể chạy độc lập.

CHẠY TRÊN MÁY
1. Giải nén ZIP.
2. Mở thư mục ban-do-triet-hoc trong Visual Studio Code.
3. Mở index.html.
4. Chạy bằng tiện ích Live Server (nếu đã cài), hoặc mở trực tiếp index.html trong trình duyệt.

ĐƯA LÊN INTERNET
- GitHub Pages: tạo repository, tải index.html lên thư mục gốc, vào Settings > Pages và chọn nhánh triển khai.
- Netlify: kéo thả thư mục chứa index.html lên khu vực triển khai thủ công.
- Vercel: import repository chứa index.html; với trang tĩnh đơn giản này không cần build command.

LƯU Ý
- Đây là website tĩnh, không cần backend hoặc cài thư viện.
- Font Nunito được gọi từ Google Fonts; nếu không có Internet, trang vẫn hoạt động nhưng có thể dùng font dự phòng.
- Điểm trong phiên làm bài được tính ngay trên trình duyệt; bản hiện tại không lưu điểm giữa các thiết bị hoặc gửi điểm về máy chủ.
